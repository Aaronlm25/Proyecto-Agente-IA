# Demostración por inducción

La demostración por inducción matemática consta de dos pasos principales: 1. Paso Base (Paso Inicial): Demostrar que el enunciado es verdadero para un valor base, comúnmente para n = 1. 2. Paso de Inducción: Suponer que el enunciado es cierto para algún número natural k (hipótesis de inducción) y usar esta suposición para probar que el enunciado también es cierto para k + 1. Si ambos pasos son válidos, podemos concluir que el enunciado es cierto para todos los números naturales.
